## [1.6.0] - 02.09.2026

### 🔔 Уведомления
- Добавлены локальные уведомления о биоритмах, которые включаются пользователем; время ежедневной доставки настраивается, значение по умолчанию — 09:00.
- Добавлена ежедневная сводка с независимым выбором физического, эмоционального и интеллектуального циклов, их значений и направления.
- Добавлены уведомления о важных событиях: критических точках, пиках, минимумах и синхронных экстремумах ±80%; ежедневную сводку можно отключить и получать только важные события.
- На Android 13+ разрешение на уведомления запрашивается только при включении функции; при системной блокировке можно сразу открыть настройки уведомлений приложения Android.

### 🐛 Надёжность
- Доставка использует один неточный будильник `AlarmManager.setAndAllowWhileIdle` и не запрашивает `SCHEDULE_EXACT_ALARM` или специальный доступ к точным будильникам.
- Следующее локальное уведомление пересчитывается после каждой доставки, а также после загрузки устройства, ручного изменения времени, смены часового пояса, системной локали и обновления приложения.
- Добавлена защита от повторной доставки в пределах одних локальных суток: повторный запуск receiver не создаёт второе ежедневное уведомление.
- Исправлена публикация релизов: отсутствие тега версии теперь определяется корректно, а новый тег создаётся только на проверенном release-коммите перед публикацией GitHub Release.

### ✅ Качество
- Добавлены unit-тесты расписания на текущие/следующие сутки, перехода DST, тишины обычного дня в режиме только важных событий и решений о доставке важных событий.
- Добавлен instrumentation-тест API 37, который выдаёт разрешение, реально публикует локализованное уведомление через `NotificationManager` и проверяет его заголовок.

### 📦 Релиз
- Версия приложения обновлена до `versionCode` 11 и `versionName` `1.6.0` без изменения `minSdk = 26`, `targetSdk = 37` и `compileSdk = 37`.

## [1.5.0] - 02.09.2026

### ✨ Добавлено
- Добавлен прогноз на семь дней для физического, эмоционального и интеллектуального циклов.
- Для каждого прогнозируемого значения добавлены индикаторы роста, снижения и стабильного направления.
- Добавлено определение критических дней, локальных пиков и локальных минимумов каждого классического цикла.
- Добавлено отдельное предупреждение, когда все три цикла одновременно находятся не ниже +80% или не выше −80%; оно отображается для выбранного дня, в строках прогноза и в виджете домашнего экрана.

### ♿ Интерфейс и виджет
- Значения в виджете теперь содержат стрелки направления циклов и при необходимости показывают предупреждение о синхронном экстремуме.
- Предпросмотр настройки виджета повторяет индикаторы направления и предупреждение, отображаемые реальным виджетом.

### 🐛 Надёжность
- Добавлено одно неточное локальное суточное обновление виджета, чтобы значения менялись после полуночи без специального доступа к точным будильникам; системное суточное обновление AppWidget сохранено как резервный механизм.
- Виджеты теперь обновляются и перепланируют следующее обновление после загрузки устройства, ручного изменения времени, смены часового пояса, системной локали и обновления приложения.
- Индивидуальная прозрачность виджета сохраняется при восстановлении Android с переназначением widget ID; на API 30+ отмечается успешное завершение восстановления.
- Добавлено восстановление после повреждения Preferences DataStore: повреждённый файл сбрасывается к безопасным значениям по умолчанию вместо последующих ошибок чтения.

### ✅ Качество
- Добавлены регрессионные тесты длины прогноза, событий циклов, поведения порога ±80% и отображения синхронного предупреждения в предпросмотре виджета.
- Добавлены регрессионные тесты границ обновления для високосного дня и DST, а также перекрывающегося переназначения widget ID.

### 📦 Релиз
- Версия приложения обновлена до `versionCode` 10 и `versionName` `1.5.0` без изменения `minSdk = 26`, `targetSdk = 37` и `compileSdk = 37`.

## [1.4.3] - 02.09.2026

### 🧹 Обслуживание
- Ручной lifecycle observer в Compose заменён на `LifecycleEventEffect` с сохранением прежнего обновления при `ON_RESUME` и немедленного обновления виджета.
- Удалена лишняя прямая зависимость `lifecycle-runtime-ktx` после подтверждения, что приложение компилируется с непосредственно используемыми lifecycle Compose/ViewModel артефактами.
- Версия top-level Kotlin Gradle Plugin привязана к единому version catalog, чтобы исключить расхождение с версией Compose plugin.

### ⚡ Производительность
- Android `Resources` явно выбранного языка переиспользуются между recomposition вместо повторного создания configuration context для каждого локализованного string lookup.
- Форматированный текст процентов в preview виджета кэшируется, поэтому recomposition при перемещении opacity-slider больше не повторяет неизменившиеся расчёты и форматирование.

### 📦 Совместимость с Google Play
- Подтверждены `minSdk = 26`, `targetSdk = 37` и `compileSdk = 37` с текущим toolchain AGP 9.3.2 без дополнительного повышения требований к платформе.
- Подписанный AAB назначен основным release-артефактом для Google Play, а подписанный APK сохранён как дополнительный артефакт для GitHub и прямой установки.
- Добавлена проверка release-артефактов: `arm64-v8a`, 64-битные аналоги поставляемых 32-битных библиотек, допустимые ABI, одинаковый native-состав APK/AAB, 16 KB ELF alignment, 16 KB ZIP alignment APK и `PAGE_ALIGNMENT_16K` в AAB.
- Добавлена явная runtime-проверка, что API 37 emulator для instrumentation-тестов действительно использует memory page size 16 KB.
- Подтверждено, что текущие транзитивные native-библиотеки AndroidX поставляются для `arm64-v8a`, `armeabi-v7a`, `x86_64` и `x86` и совместимы с 16 KB page size.

## [1.4.2] - 01.09.2026

### 🧹 Обслуживание
- Выполнены полный аудит репозитория, глубокая очистка и рефакторинг с сохранением существующего поведения, UI/UX, форматов хранения данных, контрактов виджета и release-процесса.
- Удалены избыточные Android/Gradle-настройки, дублирующий `.gitignore` модуля, повторная настройка темы widget activity и ненужные внутренние проверки/clamp.
- Временные `Map` для значений биоритмов заменены на упорядоченные списки, устранена повторная подписка на состояние даты рождения.
- Виджет теперь использует общую проверку сохранённой даты рождения вместо дублирования преобразования даты и проверки будущих значений.
- Compose-подписки на `StateFlow` переведены на lifecycle-aware сбор, чтобы не выполнять лишнюю работу, когда Activity неактивна.
- Gradle обновлён с 9.5.1 до 9.7.1; закреплена официальная SHA-256 дистрибутива и обновлены строгие metadata dependency verification для нового build graph.
- Espresso 3.7.0 оставлен как явный version pin: проверка показала, что он необходим для сохранения совместимых версий Android test dependency graph.

### ✅ Качество
- После рефакторинга и обновления Gradle повторно пройдены unit-тесты, компиляция Android-тестов, Android Lint, неподписанные release APK/AAB, runtime instrumentation-тесты на API 37, CodeQL и SonarQube Cloud.

## [1.4.1] - 01.09.2026

### 🐛 Исправлено
- Исправлено падение при открытии **Настройки → Дата рождения**: системный диалог выбора даты заменён на Material 3 Compose DatePicker, а владельцем окна диалога остаётся Activity-context.
- Выбор даты рождения теперь использует выбранный в приложении язык, запрещает будущие даты и сохраняет календарную дату без сдвигов из-за часового пояса или DST.
- Заголовок виджета и accessibility-текст кнопки настроек теперь используют выбранный в приложении язык, а не системную локаль.
- Предпросмотр настройки виджета теперь соответствует реальному виджету домашнего экрана и больше не показывает визуальные полосы, которых в самом виджете нет.

### 🧹 Обслуживание
- Gradle Wrapper обновлён до 9.5.1 с зафиксированной контрольной суммой дистрибутива.
- Исправлена проверка подписи release APK: `apksigner` запускается по пути установленного Android Build Tools, при этом обязательная проверка подписи сохранена.
- Усилена проверка релизной подписи: AAB публикуется только если `jarsigner` явно подтверждает успешную проверку.
- Удалены неиспользуемая легенда графика, устаревшие цветовые ресурсы виджета и пустой пользовательский ProGuard-файл.
- Добавлены runtime-регрессионные проверки открытия выбора даты рождения и остальных интерактивных строк Settings, а также проверки локализации и содержимого предпросмотра виджета.

## [1.4.0] - 31.08.2026

### 🔐 Безопасность и надёжность
- Production signing APK/AAB вынесен из обычных push в `main` в отдельный release workflow, который работает только с тегом версии или явно указанным тегом при ручном запуске.
- Перед использованием production signing secrets добавлена проверка соответствия тега версии приложению.
- DataStore-файл с датой рождения исключён из облачного резервного копирования Android.
- Добавлены обработка ошибок чтения/записи DataStore, откат состояния при ошибке сохранения и дополнительная валидация даты рождения.
- Явно запрещён незашифрованный cleartext-трафик.
- Добавлен Gradle dependency verification с зафиксированными SHA-256 зависимостей.
- Добавлены CodeQL и SonarQube Cloud; их проверки включены в защиту основной ветки.
- Для репозитория включены Dependabot vulnerability alerts и security updates.

### ✅ Качество
- Добавлен реальный запуск Android instrumentation-тестов на API 37 и еженедельная проверка совместимости на API 26.
- Добавлены runtime-проверки accessibility semantics для графика и предпросмотра виджета.
- Защищённая ветка `main` теперь требует успешных проверок `Verify`, `CodeQL` и `SonarCloud Code Analysis` перед merge.
- График, состояние/действия экрана настроек и общие UI-компоненты переработаны для снижения cognitive complexity и дублирования без изменения поведения приложения.
- Дублирование нового кода снижено ниже установленного порога Sonar; все обоснованные замечания Sonar устранены.
- Повторяющаяся настройка Android/Gradle в CI вынесена в локальный переиспользуемый action.
- CI устанавливает только действительно необходимые Android SDK components.
- Dependabot снова предлагает patch-обновления Gradle Wrapper, а minor/major остаются ручным решением.

### ♿ Интерфейс и виджет
- Bitmap-содержимое виджета заменено нативными текстовыми строками `RemoteViews`, что уменьшает расход памяти и улучшает accessibility.
- Добавлены доступные описания значений циклов и проверка принадлежности `appWidgetId` провайдеру приложения.
- Периодическое обновление виджета уменьшено с одного часа до одного раза в сутки; немедленное обновление после изменений в приложении сохранено.
- Процентные значения переведены на контрастные цвета темы, при этом цвета циклов сохранены как визуальные акценты.
- Удалён лишний version-specific XML виджета при сохранении размеров ячеек Android 12+ и fallback-поведения старых версий Android.

### 📦 Релиз
- Версия приложения обновлена до `versionCode` 6 и `versionName` `1.4.0`.
- Release automation после успешной подписанной сборки публикует подписанные APK и AAB, а также `SHA256SUMS.txt` как постоянные assets GitHub Release.

## [1.3.0] - 27.08.2026

### ✨ Добавлено
- Первый запуск с выбором даты рождения прямо на главном экране.
- Три заметные карточки со значениями биоритмов для выбранного дня.
- Интерактивный просмотр графика: нажатие или проведение по графику выбирает другой день и сразу обновляет значения.
- Живой предпросмотр виджета на экране его настройки.
- Экран «О приложении» с кратким описанием, текущей версией, автором, лицензией и ссылкой на исходный код в GitHub.
- Unit-тесты для преобразования позиции на графике в дату и генерации сетки.
- Файл лицензии с официальным текстом PolyForm Noncommercial License 1.0.0.

### 🎨 Изменено
- Вертикальная сетка графика упрощена: вместо линии на каждый день используются понятные интервалы по пять дней.
- График стал выше; добавлен выраженный маркер выбранного дня и точки на всех трёх кривых.
- Проценты биоритмов теперь окрашиваются в цвет соответствующей линии, без отдельной красно-жёлто-зелёной шкалы.
- Экран настроек переработан: более крупные Material-строки, понятные секции и более читаемая типографика.
- Управление непрозрачностью виджета адаптировано для узких экранов.
- В предпросмотр виджета добавлена шахматная подложка, чтобы выбранная непрозрачность фона была сразу заметна.
- Увеличены основные размеры шрифтов и интервалы для лучшей читаемости.
- Лицензия проекта явно установлена как PolyForm Noncommercial 1.0.0.
- Протестированная beta-ветка 1.3 переведена в стабильный релиз `1.3.0`: `versionCode` 5, `versionName` `1.3.0`.

## [1.2.0] - 26.08.2026

### ✨ Добавлено
- Виджет домашнего экрана с текущими значениями физического, эмоционального и интеллектуального циклов.
- Индивидуальная настройка непрозрачности фона каждого экземпляра виджета с сохранением значения.
- Unit- и instrumentation-тесты для расчётов, локализации, настроек, выбора даты и параметров виджета.
- GitHub Actions CI с unit-тестами, Android Lint, release-сборкой, R8/resource shrinking, генерацией AAB и компиляцией Android-тестов.
- Безопасная конфигурация release signing через переменные окружения без хранения keystore и паролей в репозитории.

### 🐛 Исправлено
- Конфигурация виджета теперь корректно открывается при добавлении виджета через launcher.
- Существующие виджеты сразу обновляются после изменения даты рождения, языка или темы.
- Содержимое виджета корректно обновляется при изменении его размера и во время периодического системного обновления.
- Светлая, тёмная и системная темы последовательно применяются к приложению и виджету.
- Русская и английская локализация последовательно применяется к интерфейсу, форматированию дат и подписям виджета.
- Исправлена работа системной кнопки Back на экране настроек.
- Текущая дата корректно обновляется при возвращении приложения из фона и после смены суток.
- Хранение настроек темы и языка больше не зависит от порядка элементов enum.
- Исправлены проблемы с ресурсами, темами, локализацией и устаревшими файлами.

### 🏗️ Изменено
- Расчёт биоритмов вынесен в общий модуль, который используется приложением и виджетом.
- Цветовая индикация значений биоритмов унифицирована между приложением и виджетом.
- Восстановлен официальный Gradle Wrapper — проект собирается из чистого клона без отдельно установленного Gradle.
- Проект переведён с `1.2 beta 1` на стабильную версию `1.2.0`.
- `versionCode` обновлён до 4, `versionName` — до `1.2.0`.

## Схема версий

- **Major (X.0.0)**: несовместимые изменения или крупная переработка
- **Minor (1.X.0)**: новые функции и значимые улучшения
- **Patch (1.2.X)**: исправления ошибок и небольшие улучшения
